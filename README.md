# Méhdi's Online School

A Japanese-first, bilingual, responsive concept website for the existing school.

## Content and conversion

- Japanese and English versions; explicit language choice is remembered on this device.
- A fraction exercise with answer feedback and reset.
- Teacher introduction, ongoing pricing and a ¥1,000 / 60-minute trial.
- Accessible native FAQ disclosures and mobile navigation.
- Trial CTA opens the school's existing site, using a text fragment to locate the enquiry introduction. Browsers without text-fragment support open the original homepage. The new site does not collect, store or claim to send enquiries.

## Evidence and assets

Prices and school information come from user-supplied screenshots dated 22 September 2026. No school results, quotes or extra qualifications were fabricated. ¥64,000 represents eight two-hour sessions at ¥4,000/hour; actual scheduling/billing terms require confirmation with the school.

`mathematical-world.webp` is original generated illustrative artwork. It is not a school facility or teaching photograph.

`mehdi-source.webp` preserves the user's supplied screenshot `Screenshot 2026-09-22 at 17.59.30.png` in WebP format. CSS displays the actual teacher portrait from its About Mehdi graphic in a circular window. A clean original teacher photograph should replace this source for a final business launch.

No testimonial scores, enrolment figures or institutional partnerships are invented. Google Fonts supplies DM Sans and Noto Sans JP. No marketing analytics or advertising trackers are added. Local storage only remembers the display language.

## Before a public business launch

Confirm exact ages/curricula, scheduling and contractual terms; supply a clean teacher portrait and school policies. Connect the school-controlled enquiry destination if replacing the current website. This private Site is independent of the original domain and makes no changes to it.

## Preview

Serve `dist/` with a local static HTTP server. There is no dependency installation or build step. The Sites manifest identifies the static output directory.
